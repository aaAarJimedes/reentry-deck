# 复航台 · REENTRY

> 让中断只是暂停，不是重来。

复航台是一个本地优先的工作上下文恢复器。它不试图替代待办清单，而是保存普通任务工具经常遗漏的内容：你刚才在想什么、做出了什么决定、卡在哪里，以及回来时第一步该做什么。

## 核心闭环

1. 为一项长期工作建立项目。
2. 开始专注会话，写下这次工作的意图。
3. 工作中用极短的“面包屑”记录发现、决定、问题、阻塞和下一步。
4. 离开前保存检查点：当前状态、下一物理动作、未决事项和复航提示。
5. 下次打开项目时，使用自动整理的 60 秒复航卡恢复上下文。

所有内容都保存在当前浏览器中。程序不依赖账号、云服务或外部 API。

## 运行

需要 Node.js 22 或更高版本：

```powershell
npm start
```

然后打开终端显示的本地地址，默认是 <http://127.0.0.1:4173>。

也可以用任何静态文件服务器托管项目根目录。不要直接双击 `index.html`，因为浏览器会限制模块与离线功能。

## 测试

```powershell
npm test
npm run check
```

## 隐私与备份

- 数据只写入浏览器的本地存储。
- “数据保险箱”可以导出完整 JSON 备份并再次导入。
- 清除浏览器站点数据会删除本地记录，因此重要内容应定期导出。
