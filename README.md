# 复航台 · REENTRY

> 让中断只是暂停，不是重来。

复航台是一个本地优先的工作上下文恢复器。它不试图替代待办清单，而是保存普通任务工具经常遗漏的内容：你刚才在想什么、做出了什么决定、卡在哪里，以及回来时第一步该做什么。

## 核心闭环

1. 为一项长期工作建立项目。
2. 开始专注会话，写下这次工作的意图。
3. 工作中用极短的“面包屑”记录发现、决定、问题、阻塞和下一步。
4. 离开前保存检查点：当前状态、下一物理动作、未决事项和复航提示。
5. 下次打开项目时，使用自动整理的 60 秒复航卡恢复上下文。

所有内容都保存在当前浏览器中。程序不依赖账号、云服务或外部 API。

## 已实现能力

- 项目舰桥、状态管理与带可访问内置确认的可恢复归档
- 活动或归档项目可复用为新的起步现场，只带入名称、目的、第一动作和颜色，不复制任何历史记录
- 真实时间戳会话计时，以及不同类型的快捷工作轨迹
- 手工可靠检查点与无需填写表单的“快速停靠”；活动会话可按 `Ctrl/⌘ Shift S` 应急收拢
- 快速停靠保留完整原始轨迹，同时把派生动作与合并未决事项安全压入检查点字段边界，并忽略已解决事项
- 带来源时间的证据化复航卡：检查点后变化、最近决定和未解决事项
- 一键复制结构化复航简报，把当前状态、第一动作、实时未决、返回提示和证据缺口带到邮件、聊天或笔记
- 复航完整度附带可执行缺口：指出应补状态、下一动作、可靠检查点、材料入口，或先核对未收拢会话
- 快速停靠可通过专用复核表单升级为新的人工可靠检查点，强制替换“未记录”占位内容且保留原历史
- 问题 / 阻塞可解决并重新打开，现场缺口会动态下调完整度
- 关键轨迹可设为置顶航标，并作为独立证据进入复航卡；卡片保留最新三条正文并披露其余航标数量
- 跨天或超过 12 小时的未收拢会话提示与接续处理
- 本地主题、响应式布局、键盘入口和基础无障碍语义
- 全局快捷键尊重模态边界，不会在表单、确认框或导入预览背后叠开对话框或触发撤销
- 动态效果默认尊重系统辅助功能偏好，也可在应用内持久化强制减少
- 跟随系统主题会实时同步页面与浏览器窗口色彩，显式明暗选择保持优先
- 表单输入上限与持久化模型共享单一契约；派生文本按完整 Unicode 码点省略，不会切坏 emoji
- 搜索结果摘要和备份信封元数据同样使用 Unicode 安全压缩，长文本不会泄漏孤立代理字符
- 跨导航与同步刷新仍可靠保留的短时操作反馈，统一按到期时间清除
- 安全 JSON 备份：新导出含非加密内容校验码；文件读取前执行 25 MB 页面稳定性上限，之后校验完整性、引用、时间、文本容量与状态，并预览新增、更新、移除和活动会话影响
- 新建、备份恢复、载入示例和撤销恢复成功后都会尽力请求浏览器持久存储；不支持或被拒绝时仍保持本地保存与 JSON 导出路径可用
- 应用启动时只读恢复浏览器的现有持久保护状态；数据保险箱也可主动请求保护，并明确区分已保护、未授予、无法自动确认、不支持或检查失败，部分实现不会错误禁用请求，任何非授予结果都会继续提示导出 JSON
- 备份下载在浏览器接管后延迟释放临时对象 URL，异常路径仍立即回收资源
- 备份文件名跨平台投影会避让 Windows 经典、控制台及上标数字设备别名，扩展名前的尾空格也不能绕过判断
- 多次选择备份文件时只采用最后一次读取；旧读取和已销毁实例的异步完成不会覆盖当前预览
- 设置页按 UTF-16 估算本应用与来源总占用，并以 5 MiB 保守参考线在 80%/100% 分级提醒导出（实际浏览器配额可能不同）
- 导入与本地新增共享 50,000 条总记录安全上限，越界写入在持久化前原子拒绝
- 本地编辑与导入、启动恢复、滚动快照和跨标签同步共享完整内容、引用、枚举与因果时间校验，非法状态不会先落盘再等待重启发现
- 工作区容器与记录只接受普通 JSON 对象，特殊对象不能借序列化变形制造“保存成功、重启损坏”
- 持久化文本与 ID 拒绝零宽空格、双向覆盖和非排版控制字符，避免不可见内容伪装项目名或工作证据，同时保留文字塑形与组合 emoji 所需的连接符
- 所有持久化时间统一为带毫秒的 UTC ISO 格式，拒绝依赖浏览器地区解析的模糊日期
- 逻辑时间锚点抵御系统时钟回拨：工作区修订、会话证据、检查点、解决/航标与项目状态不会倒退
- 同一毫秒内的连续轨迹、检查点与会话以持久化插入顺序消歧，后写入证据立即成为最新现场
- 严格备份校验会话区间：来源/结束检查点、会话内轨迹、解决时间与活动状态必须保持因果顺序
- 工作区、项目及其会话/轨迹/检查点时间必须落在各自创建—更新窗口内，接续停靠也会把工作区时间推进到新会话
- 多标签页同步、恢复前台或页面缓存还原时的遗漏事件补偿、覆盖冲突保护、损坏外部写入的可见告警，以及外部刷新时的未提交表单保护
- 对外发布的工作区快照不可变，任何更改必须经过带校验、冲突保护与原子持久化的 `update()` 边界
- 状态订阅异常与持久化提交隔离，单个界面观察者失败不会把已保存写入误报为失败或阻断其他观察者
- 导入、重置、撤销与外部同步共享单调修订号；结构合法但版本倒退的外部状态也不会覆盖当前工作区
- 外部工作区必须同时满足修订号前进和更新时间不倒退，不能以伪造高修订绕过逻辑时间保护
- 其他标签页通过单键删除或 `localStorage.clear()` 清空站点数据时，已打开页面都会同步到更高修订的空工作区
- 浏览器拒绝本地存储访问时应用仍可解释地启动；运行中读取权限消失不会清空或覆盖当前内存状态
- 点击、选择与键盘命令共享用户操作错误边界，过期标签页的冲突拒绝始终转成可见反馈
- 错误提示统一经过单次属性读取、有界扫描与 Unicode 修复，异常对象本身不能击穿界面捕获边界
- 带状态级惰性索引的本地全局搜索与快捷命令面板（`Ctrl/⌘ K`、`/` 或 `?`），以及安全 HTTP(S) 复航资源识别
- 复航资源拒绝凭据、不可见控制码与超长 URL，外链明确提示新标签页；本地服务器提供不含内联样式豁免的 CSP、权限与防嵌入响应头
- 资源 URL 与项目路由在百分号解码前后共享 C0/C1、零宽和双向控制字符边界
- 哈希路由严格拒绝畸形百分号、额外路径段、控制字符和超长项目 ID，坏链接稳定显示“页面未找到”而不会回落到首页
- 跨页面快捷捕获（`Ctrl/⌘ Shift C`）：选择项目、证据类型与可选置顶，不打断当前视图
- 全局搜索会扫描完整本地索引并报告真实命中总数，同时只把排序最高的前 40 项放入结果 DOM
- 七日航迹、近距项目切换与可解释的工作区关注清单；四项关注窗口和三条未决正文都保留完整总数或余量，复制简报也不会隐去窗口外事实
- 可调 1–365 天的离开提醒阈值，让关注清单适配短周期推进或长期研究而不是写死七天
- 单份滚动安全快照、可逆撤销/重做与多标签冲突保护；浏览器配额临界时优先保住主数据并明确告警
- 大型项目时间线、项目舰桥与归档舱分批渲染，保留全量计数、排序、搜索与键盘焦点续接
- 批量复航证据索引：工作区推荐与洞察对每个集合只扫描一次，不随项目数形成重复全量过滤
- 安装式 PWA 外壳和离线缓存
- 自动发布契约核对应用/备份/离线构建版本、PWA 启动范围与图标、运行时模块依赖、HTTP 白名单和离线外壳，防止版本漂移或安装、刷新、离线启动时缺文件
- 本地服务严格解析完整十进制端口、捕获文件探测竞态，并让 GET/HEAD/错误响应提供准确内容长度；端口冲突和监听权限不足会给出简洁可操作的启动提示，未知故障仍保留完整诊断
- 可幂等销毁的应用生命周期：释放界面事件、跨标签监听、状态订阅、计时器与短时提示任务
- 首次界面渲染采用失败即回滚的原子启动，部分安装的监听器、订阅和计时器不会滞留在恢复页面背后
- 原子安装的离线外壳：不完整部署或缓存写入失败不会留下半套新版本，旧版本继续可用
- 在线导航或模块超过 4 秒仍未响应时主动中止并回退到最后完整离线外壳，避免弱网让页面无限等待
- 在线服务短暂 404/5xx 时回退完整缓存；运行时缓存刷新配额失败也不会遮蔽成功网络响应

## 运行

需要 Node.js 22 或更高版本：

```powershell
npm start
```

然后打开终端显示的本地地址，默认是 <http://127.0.0.1:4173>。

若默认端口已被占用，可让操作系统选择空闲端口；终端会显示实际可打开的地址：

```powershell
$env:PORT=0
npm start
```

若显式端口已被其他程序占用，服务会显示冲突的主机与端口并以失败状态结束；权限不足会提示改用普通端口，其他异常保留完整堆栈供排查。

`HOST` 可使用 ASCII / Punycode 主机名、IPv4、裸或带方括号的 IPv6；不要填入完整 URL、端口或路径。空值和畸形值会在 DNS 前拒绝。默认回环地址只允许本机访问；显式设置 `0.0.0.0` 或 `::` 会监听所有接口，只应在可信网络中使用。

也可以用任何静态文件服务器托管项目根目录。不要直接双击 `index.html`，因为浏览器会限制模块与离线功能。

## 隐私与备份

- 数据只写入浏览器的本地存储。
- “数据保险箱”可以导出完整 JSON 备份并再次导入。
- 同一站点的多个标签会实时采用较新的写入；发现过期快照时会阻止覆盖。
- 清除浏览器站点数据会删除本地记录，因此重要内容应定期导出。
