# 验收清单

## 自动化门槛

每次提交前运行：

```powershell
npm run check
npm test
git diff --check
```

测试范围包括模型迁移与导入拒绝、导入容量与跨项目引用、损坏主数据恢复、导入差异预览、时间线与项目集合窗口、批量复航索引、状态级搜索索引、存储失败回滚、滚动快照撤销/重做、多标签覆盖保护、返航卡回退、会话陈旧检测、快速停靠证据边界、搜索排序、链接安全、七日统计、关注清单、时间格式和本地服务器白名单。

## 核心人工路径

1. 新建项目 → 开始会话 → 留下发现/决定/下一步 → 保存手工检查点 → 刷新 → 复航卡内容一致。
2. 开始会话 → 只留一条轨迹 → 快速停靠 → 会话结束 → 卡片标记“请先复核”且完整度不超过 50%。
3. 疑似遗留会话 → 继续原会话 / 补检查点 / 快速停靠 / 中断并接续，四条路径都不重复创建记录。
4. 两个标签同时打开 → 标签 A 保存 → 标签 B 自动看到变化；极端竞态下旧写入被拒绝而不覆盖；损坏外部写入只告警一次并保持当前有效现场。
5. 导出 → 核对 JSON 信封含格式正确的内容校验码 → 从有效备份恢复；修改数据但保留旧校验码、集合损坏、孤立引用、重复 ID 和多活动会话必须拒绝；无校验码旧信封保持兼容。
6. 归档项目深链接只读；恢复后才能开始新会话。
7. `/%` 返回 HTTP 400，`/.git/config`、`/package.json` 和 `/tests/*` 返回 404，随后首页仍可访问。
8. 检查点后记录新的下一步 → 复航动作采用新记录并显示来源时间；更旧记录不能覆盖检查点。
9. 问题 / 阻塞标记已解决 → 从未决清单消失 → 重新打开后恢复；每一步焦点都停留在对应操作按钮。
10. `Ctrl/⌘ K` → 空查询显示七个常用动作 → 输入多个关键词后切换为证据结果 → 清空后恢复动作；结果包含来源和时间，打开后到达正确项目，空结果有明确提示。
11. 记录 HTTP(S)、危险协议和畸形 URL → 只显示合法去重资源；外链必须带 `noopener noreferrer`。
12. 七日航迹只计窗口内会话，异常长会话封顶并标注；近距切换必须是 4 小时内不同项目的相邻会话。
13. 关注清单原因与项目事实一致，归档和健康项目不应制造虚假告警；点击后到达对应项目。
14. 连续保存两次 → 撤销回到前一版本且修订号继续增加 → 再次撤销切回；损坏快照和过期标签恢复必须拒绝。
15. 选择有效备份 → 先看到新增/更新/移除数量与活动会话警示 → 取消不改变数据；预览期间其他标签写入后必须重算并要求再次确认。
16. 含 75 条以上轨迹的项目首屏只渲染 30 条 → 每次再显示最多 30 条 → 焦点进入第一条新记录 → 总数、搜索和导出仍覆盖全部轨迹。
17. 导入畸形时间、超长文本、错误设置、跨项目会话引用或超过 50,000 条记录 → 预览前拒绝且当前数据不变；错误列表不得无限增长。
18. 主数据引用损坏但滚动快照有效 → 从快照启动 → 首次保存修复主数据，同时继续保留有效快照而非缓存损坏原文。
19. 任意轨迹设为航标 → 按钮状态与焦点保留 → 复航卡按证据时间展示最多三条 → 取消后消失但时间线顺序不变。
20. 从任意页面打开快捷捕获或按 `Ctrl/⌘ Shift C` → 默认选择当前/活动项目 → 保存后留在原页面；目标会话关联、下一步同步和置顶状态准确。
21. 新建、搜索、快捷捕获等对话框打开后，焦点优先进入显式 `autofocus` 字段而不是顶部关闭按钮。
22. 搜索空态中的快捷记录命令 → 搜索框关闭 → 快捷记录打开且焦点进入文本框；无项目/无快照时对应动作准确禁用。
23. 标签 A 在普通对话框输入未提交草稿并保留字段焦点 → 标签 B 保存有效变化 → A 刷新投影后对话框、文字、选项、光标与焦点仍在；文件输入和已失效选项不恢复。
24. 含 13 个以上未归档或归档项目的视图首屏只渲染 12 张卡 → 概览和排序仍覆盖全部 → 每次再显示最多 12 张 → 焦点进入第一张新卡；390px 控制区单列且无溢出。
25. 1,000 个项目与 5,000 条轨迹批量生成复航卡 → 每个共享集合只建一次索引 → 每张卡仍保留对应项目最新五条证据，不存在的项目不产生投影。
26. 50,000 个搜索候选建立一次索引 → 连续关键词查询复用规范化文本 → 只返回真实命中并服从 100 条硬上限；清空输入恢复七个命令且焦点仍在搜索框。
27. 新导出信封的校验码与数据一致 → 往返导入成功；修改任何合法字段但保留原校验码 → 在预览前拒绝；错误格式拒绝，旧信封显示未验证而不误称完整性已确认。
28. 主数据写入触发明确配额异常且存在滚动快照 → 释放快照后只重试一次 → 成功则主数据落盘并告警，失败则原主数据不变并尽力恢复快照；普通错误不得删除快照。
29. 完成会引发状态重投影和 hash 导航的操作 → 新页面仍显示同一条成功反馈 → 任意中间重渲染不复制或提前移除 → 约 3.6 秒后队列与 DOM 同时清除。
30. 项目页选择归档 → 应用内对话框读出准确项目名与数据保留说明，焦点默认在取消；取消后项目与 URL 不变，确认后进入归档舱，恢复后重新出现在舰桥；确认前新出现活动会话时必须拒绝。
31. 备份文件恰好 25 MB 可进入解析，超过 1 字节必须在调用 `file.text()` 前拒绝；缺失/不可信大小、读取失败和畸形 JSON 显示稳定中文错误，同一状态的设置页重渲染不重复计算备份大小。
32. 让恢复项目、航标/解决状态、主题或命令面板动作遭遇过期标签写入 → 当前有效数据自动采用且旧写入拒绝 → 页面显示可见错误而非未处理事件；未知异常也提供稳定重试提示。
33. 新增、移除或重命名任一运行时模块 → 自动递归依赖审计必须在 HTTP 白名单或离线外壳缺失时失败；孤立缓存模块和 package/备份/版本记录不一致同样阻止提交。
34. 销毁应用两次 → 根节点与窗口操作不再触发旧实例，状态订阅和提示计时器全部清除；随后派发跨标签存储事件，已销毁存储对象不得采用或发出更新。
35. 服务工作线程安装时让一个外壳请求返回 404 → 安装失败且新缓存保持空；完整安装后激活只清理旧应用缓存，断网导航与带查询参数的模块命中规范缓存，POST 和跨源请求不拦截。
36. 完整缓存存在时让导航返回 503、已知模块返回 503 → 均回退缓存；未知模块返回 404 保持 404。让网络返回 200 但 `cache.put` 报配额错误 → 仍把新鲜网络内容交给页面。
37. 资源文本包含凭据 URL、`%00`、双向控制码、畸形转义和超过 2,048 字符的 HTTP(S) 目标 → 全部不渲染；合法本机/公网链接去片段去重，外链名称说明新标签页且保留 `noopener noreferrer`。
38. 首页与错误响应均包含 CSP、空权限策略、`Cross-Origin-Resource-Policy: same-origin`、`X-Frame-Options: DENY` 和 `nosniff`；现有模块、样式、图标、清单及服务工作线程仍正常加载。
39. 导入时间分别使用规范毫秒 UTC、无毫秒 UTC、`+08:00` 偏移、美式日期和 RFC 日期 → 只有应用生成的 `YYYY-MM-DDTHH:mm:ss.sssZ` 接受，其余在任何归一化或写入前拒绝。
40. 先以较晚时钟保存工作区/项目/会话，再把系统时钟回拨后记录、停靠、解决、置顶、归档或恢复 → 新业务时间取相关锚点最大值，修订号仍递增，任何证据与会话结束时间都不倒序。
41. 构造来源检查点晚于接续开始、结束检查点早于开始/晚于结束、会话轨迹越界、解决时间倒序或活动会话含结束检查点的备份 → 逐项在预览前拒绝，当前工作区不变。
42. 当前修订高于旧备份 → 导入后修订为当前 + 1；重置同样前进。外部标签写入更低/相同修订的合法状态 → 拒绝并告警；移除主键 → 采用空工作区但修订继续 +1，下一次保存仍前进。
43. 另一标签页调用 `localStorage.clear()` → 当前页收到 `key === null` 后同步为空工作区且修订 +1；来自其他存储区或无关键的事件 → 完全忽略。
44. 外部状态修订号高于当前、但 `meta.updatedAt` 早于当前 → 拒绝并产生可见告警，当前页面状态保持原对象不变。
45. 容量估算包含 UTF-16 键和值，分别统计本应用与整个来源；跨过 5 MiB 参考线的 80%/100% → 设置页显示预警/临界状态；存储不可读或阈值无效 → 安全降级为不可用而不阻断设置页。
46. 本地更新将记录总量推到 50,001 → 基础校验在遍历记录前拒绝，当前内存对象与持久化原文都不改变；50,000 条导入边界保持一致。
47. 打开未知路由、设置/归档额外段、缺失项目 ID、非法 `%`、控制字符、201 字符解码 ID 或超过 2,400 字符编码段 → 统一显示未找到；合法 Unicode 和编码斜杠项目 ID 正常解析。
48. 构造工作区更新早于创建、项目辅助时间越出项目窗口、会话/轨迹/检查点越出所属项目窗口的备份 → 逐项拒绝；快速停靠并接续 → 工作区更新时间至少达到新会话开始时间。
49. 导航或外壳模块网络请求永久悬挂 → 4 秒后中止并返回最后完整缓存；成功请求及超时回退后均无残留计时器。
50. `PORT=4173abc`、小数、符号或越界值 → 启动前拒绝；合法 0/4173/65535 接受。静态 GET 与 HEAD 内容长度一致，HEAD 无正文；缺失文件的同步探测异常稳定返回 404。
51. 空白项目 → 显示摘要、下一动作、可靠检查点三个缺口；快速停靠且字段齐全 → 只提示复核低置信度检查点；可靠检查点缺恢复入口 → 只提示材料入口；检查点后未收拢会话 → 优先提示核对段数。
52. 从最新快速检查点打开复核 → 有效内容生成脱离旧会话的新人工检查点并保留原记录；表单过期、最新检查点已变化、项目不可用或仍含摘要/下一动作占位 → 原子拒绝并显示错误。
53. 在同一毫秒依次写入两条轨迹、两个检查点或两段会话 → 后写入者成为复航卡、会话来源与时间线的最新证据；投影不得重排状态中的原始数组，畸形时间降级仍保持稳定。
54. 通过本地更新尝试写入超长字段、孤立引用、跨项目关联、非法枚举或非规范/越界时间 → 全部在 `localStorage` 写入前原子拒绝，内存状态、主数据和订阅均不变化；合法 50,000 条边界仍可提交。
55. 记录 601–1,200 字的“下一步”轨迹 → 原轨迹完整保留，项目动作和快速停靠动作压至 600 字且末尾有省略号；合并多条未决事项不超过 800 字，已解决问题不进入快速检查点；复核表单绕过 `maxlength` 后仍拒绝超长值。
56. 让派生文本的截断边界落在 emoji 代理对中间 → 输出只包含完整 Unicode 码点且不超过模型上限；新建、编辑、会话、轨迹、检查点与复核表单的 `maxlength` 均与 `IMPORT_LIMITS` 对应字段一致。
57. 先选择读取缓慢的备份 A、再选择更快的 B → 只显示 B 的预览，A 后完成不覆盖也不报错；读取期间销毁应用 → 完成后不重绘、不弹框、不清空新实例控件。
58. 在数据保险箱把离开提醒从 7 天改为 14 天 → 数字设置持久化、焦点保留且关注清单按新值重算；导入 5 天时控件增加并选中 5 天，0、366、分数或非数字均拒绝。
59. 动态效果选择“减少动效” → 根节点标记 `reduce`、平滑滚动关闭且动画/过渡近零，刷新和另一标签保持；切回“跟随系统” → 根节点恢复 `system`，系统 `prefers-reduced-motion` 仍独立生效。
60. 主题为“跟随系统”时切换操作系统深浅色 → 页面配色和 `theme-color` 同步变化；固定明亮/深色后系统切换不覆盖；销毁应用再触发媒体变化 → 旧实例不再更新页面。
61. 打开新建/编辑/检查点/导入/归档任一模态后按 `Ctrl/⌘ K`、`Ctrl/⌘ Shift C`、`Ctrl/⌘ Z`、`N`、`C`、`/` 或 `?` → 不叠加模态、不导航、不改变后台状态；Escape 关闭后同一快捷键恢复。
62. 搜索含换行且在 150 单元边界跨越 emoji 的证据 → 摘要折叠为空格、以省略号结束且无孤立代理字符；导入超长 emoji 版本元数据 → 同样完整截断在 80 单元内。
63. 导出备份 → 隐藏链接接入文档后才点击，对象 URL 至少延迟 1 秒撤销；模拟点击或调度器抛错 → 链接移除且对象 URL 立即、仅一次释放。
64. 在项目名、下一步、轨迹、检查点或任一 ID 中粘贴零宽空格/双向控制符 → 本地保存与导入都原子拒绝并明确报错；普通多行文本的换行、回车、制表与 ZWJ 组合 emoji 继续接受；危险备份版本元数据不展示。
65. 资源 URL 或项目哈希的原文/百分号编码路径包含 NEL 等 C1、零宽或双向控制符 → 资源不渲染、路由进入未找到；普通 Unicode 项目 ID 和合法 HTTP(S) 资源保持可用。
66. 把工作区根、元数据、设置、界面状态或任一记录替换成 `Date`/`Map`/`Set` → 导入与本地提交都在 JSON 写入前原子拒绝，内存状态、主键原文和订阅不变化。
67. 让 `localStorage` 属性或 `getItem()` 抛 `SecurityError` → 启动显示临时工作区与明确通知而非白屏；运行后撤销读取权限 → 外部刷新保留当前对象，保存前核对原子失败且不覆盖未知主键。
68. 尝试直接修改 `getState()`/订阅得到的项目字段、设置或集合数组 → 严格模式立即抛错，内存与持久化原文不变；通过 `update()` 克隆配方修改 → 正常提交并发布新的冻结状态身份。
69. 第一个状态订阅连续抛错、第二个正常计数 → 两次本地写入都返回成功且持久化正确，健康订阅收到两次冻结状态，故障诊断只出现一次；注册非函数立即拒绝。
70. 在项目复航卡复制简报 → 文本依次包含项目名、当前状态、第一动作、未决事项与复航提示；Clipboard API 成功不建临时节点，拒绝后回退并清理文本域；并发或销毁后旧完成不反馈。
71. 在文本输入中保留一段选区后触发旧浏览器复制回退 → 临时文本域被移除，原控件以 `preventScroll` 恢复焦点与选区；即便原控件已移除或临时节点清理抛错，也不把已成功复制误报为失败。
72. 检查点留有旧未决文本、其后新增或解决问题/阻塞，再复制简报 → 优先列出当前未解决信号；没有实时信号时以前缀把检查点文本标为“曾记录、待确认”，满容量压缩也不丢失不确定性，并附带 0–100% 完整度与当前证据缺口。
73. 预缓存完成后让运行时 `caches.open()` 或 `cache.match()` 拒绝 → 在线导航/外壳资源仍返回网络 200；再断网则分别返回清楚的导航或资源 503，而不是让 fetch 事件无响应；安装期拒绝仍不得发布残缺外壳。
74. 让运行时 `caches.open()` 永久不决、网络立即返回 200，并让模拟器拒绝事件分发后的首次 `waitUntil()` → 页面立即收到网络内容；聚合生命周期已在同步阶段登记，750ms 后正常结束且不遗留计时器。
75. 向本地服务发送绝对 URL、`//host/path`、带片段、前后空白、原始制表符、百分号编码 NUL/C1 的请求目标 → 一律 400；随后请求 `/` 仍 200，合法查询参数仍映射到白名单文件。
